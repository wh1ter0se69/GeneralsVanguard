; --- the four appended player colours --------------------------------------------------------
; These name the four MultiplayerColor blocks appended to Data\INI\Multiplayer.ini. Retail
; carries Color:Gold .. Color:Pink for the first eight; without these labels the added colours
; render as MISSING:'Color:Salmon' in the lobby's colour combo box.
;
; THE NAMES ARE PART OF THE FIX, not decoration. A player calls a colour out loud in chat, so
; two entries that share a name-region are indistinguishable in play however far apart they
; measure. The set this replaces had FIVE red-family names - Red, Maroon, Coral, Blush, Rose -
; and the owner reported exactly that: "two reds, and a pink/salmon that reads as a third red".
; These four sit in four different name regions, and each is a word people already use for a
; colour rather than a shade qualifier:
;
;   Salmon  a light warm pink-red, 25.7 deg of hue from retail Red and 47.6 from retail Pink
;   Aqua    a bright green-cyan, the one hue region retail leaves free between Green and SkyBlue
;   Rose    a deep pink-red, between Red and Pink, apart from both on the drawn models
;   Sky     a pale blue, lighter than Blue and bluer than SkyBlue
; Set A, 11/10/2026: these three replace Bronze, Forest and Teal, which looked distinct as swatches but not in
; the game (docs/WORKDIR/LOBBY_COLOURS_RENDERED.md). Same indices, same day and night values.
; Set R1, 16/10/2026 (owner pick): indices 8-11 are now Turquoise, Mint, Raspberry and Black; the names above Salmon/Aqua/Rose/Sky
; describe the earlier sets. Turquoise = bright blue-green, Mint = pale green, Raspberry = deep pink-red, Black = near-black.
