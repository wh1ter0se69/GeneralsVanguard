WS-E (rw2-E, 11/10/2026): gx_cs_ps.frag is gx_ff.frag.glsl (via #include) plus a program switch for the game's ps.1.1 shaders; fog and the alpha
test are DXVK's own post-PS stages from that file. gx_cs_trees.vert is a hand port of Trees.vso whose output interface is gx_ff.vert's. Both
fall under the same DXVK zlib notice (the FF fragment code is included, not copied). Semantics cross-checked against references/fbraz3-dxvk
src/dxso/dxso_compiler.cpp (PS 1.x constants clamp [-1,1] :1721, a float->a0 mov floors for vs<=1.1 :1855, oD0/oD1 saturate for SM<3 :3445).
No new third-party code. Regenerate with ./regen.sh (the .mut. headers are the golden's TEST-ONLY fail arms).

B · a2c-1 (20/10/2026, A108): gx_ff.frag.glsl gains a GX_LOOK_A2C block (alpha-to-coverage ramp, our own code - the formula follows B. Golus's
public write-up "Anti-aliased Alpha Test: The Esoteric Alpha To Coverage", 2017; no code copied). regen.sh compiles gx_ff.frag, gx_ff_flat.frag and
gx_cs_ps.frag with it into *.a2c.frag.h and, with GX_LOOK_SHADOWMAP too, *.sm.a2c.frag.h. Without the define every existing header is
byte-identical (regen.sh --check); the device loads the new family only with GXAlphaToCoverage on and a multisampled creation.
