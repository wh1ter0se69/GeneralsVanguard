GeneralsX reads your Zero Hour folder and never writes into it. Its own Data/INI/Multiplayer.ini and Data/English/Generals.csf stay inside the app. Older versions copied those two files into the folder; if a copy there is byte-for-byte one of ours, GeneralsX removes it. Anything else, including a file of the same name with different contents, is never touched.
