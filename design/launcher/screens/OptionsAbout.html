Where this started
This fork started from fbraz3/GeneralsX, which itself builds on TheSuperHackers/GeneralsGameCode. The cross-platform layer, the determinism work and most of the game logic have been rewritten since, so what you are running is now substantially different from both of them. The groundwork those two projects did is still underneath all of it.
