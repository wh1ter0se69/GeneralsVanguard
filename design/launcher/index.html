Launcher screens

Eleven screens, converted from the artboards in design/*.dc.html and scoped so they cannot cross-wire. Static HTML and CSS — no framework, no build step, no IPC — so each opens standalone in a browser. The fidelity check compares every one against its artboard property by property.

The two Set up screens below are the exception and are not in that check: they were written by hand, because there is no artboard for them. They follow the same structure, the same tokens and the same three injected script blocks.

StatusStates, Sidebar and BottomBar are not here on purpose: they are component sheets showing variants side by side, not screens. Main.dc.html is the superseded WinForms first draft.

Each of these is shown only on the platform it names, decided at runtime from about_info().platform — never from the user agent, because one set of files ships everywhere. Windows has neither, on purpose: its installer already knows where the retail data is. Opened standalone here they show their sample content, which is what the Tauri guard in every screen is for.
