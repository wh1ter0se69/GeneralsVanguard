Artboard → screen fidelity check

Loads each generated reference — the artboard with only its design-canvas wrappers and bindings resolved, every literal untouched — and its converted screen side by side, walks both element trees in document order, and compares the computed value of every property the conversion could have changed. The conversion is mechanical, so this is what proves the token table is correct and not merely consistent. Any row that is not 0 is a real regression.
