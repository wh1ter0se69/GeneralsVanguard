# simdigest_exclusions.txt - what the SimID digest may REACH without digesting it, each entry with its reason.
# GeneralsX @feature Claude 03/10/2026 det-codex-fixes, the boundary rule lead C11 asked for.
#
# scripts/build/simid-closure.py walks every digested object of a build - inlined code, calls and globals, overrides
# of digested virtuals - and requires each file it reaches to be digested (resources/gitinfo/simsourcedigest_watcher.cmake)
# or matched here. Anything else is a GAP: digest it, or add it here WITH the reason the simulation does not read it.
# An entry nothing reaches any more is reported stale; drop it.
#
#   <glob>          a file with no GX-SIMID regions (fnmatch; '*' also crosses '/'). Never exempts a region file.
#   sym:<glob>      a function reached OUTSIDE the regions of a region file: 'Class::fn' for a call, 'FileStem::fn'
#                   for code inlined from a header line. Functions on SIMDIGEST_REGION_FUNCTIONS need no entry.
#   class:<glob>    a subclass, declared outside the digest, of a class with virtuals in a whole-digested header.
#   base:<glob>     every such subclass of that base.
#   @<text>         the reason for the entries below it, until the next @ line; '<entry><TAB><reason>' overrides it.
#
# Not a boundary question, so on no list: NameKey ORDINALS. Every name interned earlier shifts a key minted later, GUI names
# included (ControlBar::init, window layouts); only the science range is bracketed into the identity (GameEngine::init). An
# ordinal that travels the wire raw - a map-added upgrade in MSG_QUEUE/CANCEL_UPGRADE - is the open code item 4c (Codex
# det-codex-r17): its fix is a stable wire id or a bracketed range, not digesting every layout that interns a name.

@Audio playback. The simulation reads audio state only through the SPEECH/AUDIO/MUSIC script conditions: ScriptEngine::isSpeechComplete/isAudioComplete latch AudioManager::getAudioLengthMS (digested), which picks a random variant from the logic seed and sums getFileLengthMS; MUSIC_TRACK_HAS_COMPLETED is OpenALAudioManager::hasMusicTrackCompleted, a constant FALSE. Since fix/speech-length-determinism getFileLengthMS decodes the file itself - no play cache, device or ALC context is read - so a length is a pure function of the file's bytes and the decoder. The decoder (AudioDecoder.cpp, dr_wav/dr_mp3) is not digested: Core/GameEngineDevice/CMakeLists.txt pins DR on every platform with no knob and records the gap; a per-language speech file (AudioEventRTS::adjustForLocalization) still gives a per-language length (TheSuperHackers #2320). The GameLogic isCurrentlyPlaying users only choose whether to add or remove a sound. Determinism-1 still classifies the three conditions client-local, keeping a script's bookkeeping out of the CRC but not its actions - a script acting on one is a tracked code item, not a boundary one.
